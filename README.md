# Daily Planner

A dynamic daily planner application built with React and Vite, featuring a "Cyber-Grid / Neo-Brutalist" aesthetic.

## Features

- **Dynamic Scheduling**: Add and remove tasks easily.
- **Persistent Storage**: Tasks are saved to your browser's local storage.
- **Real-time Updates**: Highlights the current task based on the time.
- **Cyber-Grid Design**: A modern, high-contrast interface with a technical feel.
- **Responsive Layout**: Works on desktop and mobile.

## Project Structure

- `src/`: Frontend React application
- `backend/`: Optional Python FastAPI backend

## Getting Started

### Frontend

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:5173 in your browser.

### Backend (Optional)

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the server:
   ```bash
   uvicorn main:app --reload
   ```

   The API will be available at http://localhost:8000.
